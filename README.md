# 📊 Sales Analysis Dashboard | Power BI Project

## 📌 Project Overview
This Power BI project presents a comprehensive sales analysis dashboard built to extract meaningful insights from sales data. The dashboard includes KPIs, category analysis, regional performance, customer insights, and time-based trends.

## 🎯 Objective
- Analyze overall sales performance  
- Identify top-performing categories, products, and customers  
- Understand regional and city-wise sales distribution  
- Track monthly sales trends  
- Enable interactive data exploration  

## 🛠️ Tools & Technologies Used
- Power BI Desktop  
- Power Query (Data Cleaning & Transformation)  
- DAX (Data Analysis Expressions)  
- Data Modeling  

## 📂 Project File
- `Power_BI Practise 5&6.pbix`

## 📊 Dashboard Features
- 📌 KPI Cards (Total Sales & Quantity)  
- 📈 Monthly Sales Trend (Line Chart)  
- 📊 Category-wise Sales & Quantity Analysis  
- 🌍 Region-wise Sales Distribution  
- 🏙️ City-wise Sales Performance  
- 🥇 Top Customers & Top Products Analysis  
- 🎯 Interactive Filters (Region & Category slicers)  

## 📈 Key Insights

### 💰 Overall Performance
- Total Sales reached **560K** with **585 units sold**

### 🛍️ Category Analysis
- **Electronics** dominates with ~340K sales and highest quantity (385 units)  
- **Accessories** contributes ~220K sales with lower volume  

### 🌍 Regional Performance
- **North region** leads with ~203K sales  
- Followed by East (~130K), South (~122K), and West (~104K)

### 🏙️ City-wise Sales
- **Delhi** is the top-performing city (~203K)  
- Followed by Kolkata (~130K), Bangalore (~122K), Mumbai (~104K)

### 📅 Monthly Trend
- Peak sales observed in **June (67K)** and **November (59K)**  
- Lowest sales in **March (30K)** indicating seasonal variation  

### 👥 Customer Insights
- Top 5 customers contribute significantly to total revenue  
- Highest contribution from a single customer ~27%  

### 🏆 Product Performance
- **Laptop** is the best-selling product (~181K)  
- Followed by Headphones (~151K) and Tablet (~86K)
